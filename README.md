# paulkroy.tech

My portfolio: client websites I've designed and built for Melbourne businesses, shown on a live map, with a public status board that monitors them every 5 minutes.

**Live:** https://paulkroy.tech. Press <kbd>X</kbd> (or open [/?xray](https://paulkroy.tech/?xray)) to switch on X-ray mode, which explains how each part of the page is built.

## Stack

- **Astro** static site with content collections (one markdown file per project)
- **React** island for the interactive MapLibre map, over a zero-JS SVG fallback
- **Svelte** island for the status board
- **Cloudflare Workers** with static assets, a cron trigger and **D1** for uptime checks

## Development

Requires Node 24+.

```sh
npm install
npm run dev        # Astro dev server at http://localhost:4321
npm run preview    # build, then run the Worker locally with wrangler (API + cron)
npm run check      # type-check
```

Test the cron locally with `npx wrangler dev --test-scheduled`, then visit `/__scheduled`.

To refresh project screenshots: `npm run screenshots` (or pass slugs, e.g. `npm run screenshots -- furtopia`).

## Deploying

```sh
npx wrangler login   # once per machine
npm run deploy       # build, verify, deploy to paulkroy.tech
```

D1 migrations live in `migrations/`. Apply new ones with `npx wrangler d1 migrations apply paul-portfolio-status --remote`.

## Layout

```
src/content/projects/   one markdown file per client project
src/assets/projects/    screenshots (generated by scripts/screenshot.mjs)
src/components/         Astro components and React/Svelte islands
src/data/xray.ts        X-ray mode annotations
worker/index.ts         Worker: /api/status and the scheduled site checks
research/               notes on what makes a good developer portfolio
```
